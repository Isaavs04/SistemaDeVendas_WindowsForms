# SistemaDeVendas_WindowsForms
Um aplicativo feito no WindowsForms para a matéria Programação Orientada a Objetos do curso Análise e Desenvolvimento de Sistemas

## ✦ Sobre
Projeto realizado em sala de aula, na matéria de programação orientada a objetos(POO), criar um projeto que permita que o usuário cadastre clientes, produtos e categorias de forma intuitiva e que permita que ele abra diversas abas de uma só vez e às organize de forma fácil(verticalmente, horizontalmente ou cascata).
